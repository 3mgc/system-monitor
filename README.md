# ThinkPad simple System Monitor
un monitor del sistema diseñado para visualizar el CPU, RAM y el Ventilador para laptops ThinkPad, exportando los datos en JSON
## Dependencias
Libreria: 
- C++: nlohmann/json.
- Python: Flask
OS
- Linux (en ThinkPads con thinkpad_acpi)
## Instalación 
```bash
git clone https://github.com/3mgc/system-monitor.git

cd system-monitor

chmod +x monitor.sh 

./monitor.sh
```
